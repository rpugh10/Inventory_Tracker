5.In your DTO you need to add the getters and setters. Use @Data from Lombok

6.Difference between orElse and orElseGet. 
orElse: expects a direct value not a lambda. Java tries to compute the value right away.
orElseGet: Uses a lambda that runs later IF the optional is empty.

7. This line .map(productMapper::toProductDTO)
.map() converts the Product to a toProductDTO
.map(productMapper::toProductDTO) is a cleaner way of writing .map(product -> productMapper.toProductDTO(product)) 
productMapper is the object the holds the tool you want to use. :: Tells Java to look inside that object for the tool. toProductDTO the name of the method you want to run.
Null Safe
The toProductDTO comes from the Mapper Interface
